# Site de Receitas para um Canal do YouTube

Sistema que permite a exibição de receitas completas de um canal do YouTube

## Como funciona

O site público contará como uma tela principal que mostrará uma breve apresentação do canal, as principais receitas e os tipos de receitas, ao escolher um tipo de receitas o sistema fornecerá ao usuário somente receitas que atendem a categoria solicitada, e ao escolher uma receita especifica, o usuário poderá ver a lista dos ingredientes que a receita leva, e poderá ver o modo de preparo via iframe do vídeo do canal.
